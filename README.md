⚠️🛠️ INSTALLATION GUIDE 🛠️⚠️

🗑️ Step 1: Remove the GalaxyAI or NowBrief_Enabler module completely
🔄 Step 2: Do a FULL reboot (⚠️ NOT a soft reboot!)
🔓 Step 3: Temp root your phone again (🧩 KernelSU / 🔐 Magisk / other root managers)
📥 Step 4: Install the AOD module first
♻️ Step 5: Soft reboot your device
🤖 Step 6: Install GalaxyAI or NowBrief_Enabler
🎊 Step 7: Soft reboot and enjoy! 🎉

📋 REQUIREMENTS 📋
📱 OneUI 9.0 (One UI 9.0 platform)
🧩 KernelSU or 🔐 Magisk / other root managers
✔️ Root or temp root access
✔️ No Mount module 👉 🐙 GitHub: https://github.com/maxsteeel/nomount
